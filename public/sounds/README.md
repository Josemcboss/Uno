# Archivos de Sonido

Este directorio contiene los efectos de sonido necesarios para el juego UNO Online.

## Archivos Requeridos

- `card-play.mp3`: Sonido al jugar una carta
- `card-draw.mp3`: Sonido al robar una carta
- `shuffle.mp3`: Sonido al barajar las cartas
- `uno.mp3`: Sonido al decir "UNO"
- `victory.mp3`: Sonido de victoria
- `game-start.mp3`: Sonido al iniciar el juego
- `achievement.mp3`: Sonido al desbloquear un logro

## Notas

- Todos los archivos de sonido deben ser cortos (menos de 2 segundos)
- Formato MP3 para mejor compatibilidad
- Volumen normalizado para consistencia
